A dense newspaper front page that sums up Wednesday 18 November 2026 in one image: 42 stories first reported that day, across 7 regions and 8 fields. Thirteen illustrated lead cards (Iran drones over the Gulf, APEC opening in Shenzhen, the COP31 fossil-fuel split, the Gaza truce warning, Bangladesh wage protests, Voyager 1 one light-day out, the Haiti gang-boss raid, Russian strikes on Ukraine, Ethiopia and Eritrea massing troops, the GTA VI launch, the Bank of England rate warning, Australia's settler sanctions, Cyclone Akvan), a world map with numbered pins, 29 one-line briefs, a day-in-numbers strip, and a date-check footer naming stories left out because they were first reported on 17 November. The program draws the whole page itself with a hand-built bitmap font and its own PNG encoder, using only the Python standard library.
